# Instrucciones para agentes

Antes de hacer commit o push en este repositorio, lee y sigue
[`MANIFIESTO-SUBIDA.md`](MANIFIESTO-SUBIDA.md). Sube siempre con
`python3 scripts/subir_por_partes.py`; nunca uses `git push --force` ni borres datos.
El repositorio es público: no subas secretos. Las fotos completas sí se suben, una sola vez por
germinadora en `devices/<id>/capturas/<día>/`; las copias viejas dentro de cada lote
(`devices/<id>/LOT-*/capturas/`) y los recortes rehechos con `scripts/recortar_desde_fotos.py`
no se suben.
